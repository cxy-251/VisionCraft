# 下位机扩充与待办

更新：2026-10-16。核对基线：`635b763`，设备页内存修复 `97a83cf`。本文件替代混合了历史设想和完成记录的旧清单；旧文可从 Git 历史查阅。

项目主线是 Qt、OpenCV 的上位机学习；下位机配合通信、控制、采集，并用于学习 FreeRTOS。这里盘点的是当前 `firmware/station` 的 F407 实践，不代表未来所有下位机，也不把 STM32 做视觉检测作为目标。

当前任务架构见 [任务架构.md](任务架构.md)。已完成 A01 设备页任务明细、A02 无SD的统一保留区诊断、A03 非存储响应基线、A04 RTC 对时、A05 波形闭环、C02 RNG游戏种子；A08 完成驱动/只读识别/划区，文件系统与卷切换仍待做。用户最新要求：不再操作其 SD 卡；后续开发不进入 FILES、不执行读写卡/诊断/插拔测试，SD 相关项保留历史记录并退出当前排期。

## 如何判断进度

- **已集成**：当前正式固件有可运行代码；验证范围以对应记录为准。
- **仅实验**：有调试器脚本、独立工具或旧固件参考，尚未接入当前正式固件。
- **部分完成**：已有基础，还缺界面、协议、异常处理或验证。
- **未实现 / 可选**：保留原任务，列出条件；不表示已经确定排期。

`handbook/Index.qml` 的 F407 卷有 **55 个条目，52 个已填写正文路径**。三个空条目是 RS232、RS485、红外 NEC。正文数量不等于正式固件集成功能数：音频正文主要记录独立实验；RTC、DAC→ADC、RNG及SPI Flash驱动已接入正式固件，SPI Flash文件系统仍是实验。

## 待验证的历史现象

- `handbook/f407/rtos/PortPriority.qml` 记过一次 BASEPRI=0x50、RTOS 节拍停止，未复现。保留诊断入口，不能把本轮已定位的 SCR 等待复位当成它的根因。
- 早期某张 JPG 偶发“没有缩略图”，原记录 66 次点击和 50 MB 连读未复现。保留各层错误计数；本轮插拔修复不等于已证明解决这个历史现象。
- 文件页长目录、文本真实文件、不同卡、坏图片、快速换卡等边界可按修改范围补测。本轮文本使用桌面假文件；相机卡未写入测试文件。
- 卡槽无检测脚，CMD13 轮询不能可靠识别两次检查间迅速换卡的身份变化；若需要支持，单独设计身份/挂载代际检查。

## 当前资源与开发约束

构建区域与运行时更新为统一诊断和设备页内存修复后的正式固件；证据见 `handbook/f407/storage/board-diagnostics-test.txt`。既有 RTC/A01/A03 和历史文件页记录仍保留，未重新操作用户卡或从卡读图复测。

| 资源 | 用量/余量 | 解释 |
|---|---:|---|
| Flash | 489460 / 1048576 B | 约 46.7% |
| 片内 RAM 区域 | 121648 / 131072 B | 链接器占用，约 92.8%；不要与运行时剩余堆混为一谈 |
| CCM | 63512 / 65536 B | 约 96.9%，DMA 不能访问 |
| 外部 SRAM 静态区 | 954628 / 1048576 B | 约 91.0%，并非仍有近 1 MB 空闲 |
| LVGL 内存池峰值 | 33636 / 45056 B | 本轮统一诊断/波形并发及10次 DEVICE 重进路径；历史文件页 35664 B，未重测 |
| StationTask 最少剩余栈 | 3996 / 8192 B | 本轮统一诊断/波形并发及图片接收；历史读图路径 2668 B，未重测 |
| FreeRTOS 最小剩余堆 | 18816 B | 统一诊断无新增堆分配；总堆配置 32768 B |

外部 SRAM 尾部 `0x680F0000` 起的 64 KB 还被 `sram` / `sdbench` / `sdsum` 等工具当作暂存区。扣除它后，静态数据末尾到该暂存区之间约 **28412 B**，不能把链接器显示的剩余约 94 KB 全部用于新缓冲。新增存储、自检和 DMA 功能必须先核对内存区间；当前已加链接ASSERT，静态区不得进入暂存区。CPU专用组帧/应答放CCM，DMA缓冲保留SRAM。
