==== Scope and limits
Physical test selects USB_232 explicitly; default tests still use simulation. The native QML test invokes button clicked and dialog accepted handlers, checks pause, replay isolation from subsequent live frames, disconnect retention, and return-to-live. Tests use non-native dialogs and do not drive the OS-native picker pixel by pixel.
The archived JSON is one actual 2048-point / 50 kS/s PA4 frame, ADC min/max404/3704, source serial, receivedAtUtc2026-10-16T13:41:58.929Z. It is not a simulated dataset and not a calibrated voltage/frequency reference. File replay does not require a board. File time is computer complete-frame reception, not hardware sample-start time.
Malformed/unknown/oversized/truncated files do not replace the last good replay. Save failure is checked against existing-file content. Raw samples and metadata, not serialized derived statistics, drive calculations. Files are single frames, not continuous recording.
