==== 1. 枚举串口 ====
  ttyACM0     28de:1205  Steam Controller
  另有 31 个没有厂商号的 ttyS*
  （示例用的伪终端：/dev/pts/8）

==== 2. 打开和配置 ====
  open：成功，波特率 115200
  同一个口再开一次：Permission error while locking the device（error 2）
  打开不存在的 /dev/ttyUSB9：No such file or directory（error 1）

==== 3. 数据一块一块地到 ====
  readyRead #1：4 字节 "T=25"
  readyRead #2：6 字节 ".3;L=8"
  readyRead #3：3 字节 "12\n"
  readyRead #4：23 字节 "T=25.4;L=811\nT=25.5;L=8"
  切出的完整行： [T=25.3;L=812] [T=25.4;L=811]
  缓冲区里剩下没收完的："T=25.5;L=8"

==== 4. 发命令 ====
  write 返回 9；刚返回时 bytesToWrite = 9；设备端收到 "GET TEMP\n"；之后 bytesToWrite = 0

==== 5. 设备被拔掉 ====
  主端关闭后 500 ms：error=0
