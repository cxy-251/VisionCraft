# 下位机扩充与待办

更新：2026-10-15。核对基线：`66ad20c`。本文件替代混合了历史设想和完成记录的旧清单；旧文可从 Git 历史查阅。

项目主线是 Qt、OpenCV 的上位机学习；下位机配合通信、控制、采集，并用于学习 FreeRTOS。这里盘点的是当前 `firmware/station` 的 F407 实践，不代表未来所有下位机，也不把 STM32 做视觉检测作为目标。

当前任务架构见 [任务架构.md](任务架构.md)。本轮仅整理文档，不执行下面的新增功能、写卡、外设实验或采购。

## 如何判断进度

- **已集成**：当前正式固件有可运行代码；验证范围以对应记录为准。
- **仅实验**：有调试器脚本、独立工具或旧固件参考，尚未接入当前正式固件。
- **部分完成**：已有基础，还缺界面、协议、异常处理或验证。
- **未实现 / 可选**：保留原任务，列出条件；不表示已经确定排期。

`handbook/Index.qml` 的 F407 卷有 **54 个条目，51 个已填写正文路径**。三个空条目是 RS232、RS485、红外 NEC。正文数量不等于正式固件集成功能数：RTC、DAC、示波器、RNG、音频、SPI Flash 等正文主要记录独立实验。

## 待验证的历史现象

- `handbook/f407/rtos/PortPriority.qml` 记过一次 BASEPRI=0x50、RTOS 节拍停止，未复现。保留诊断入口，不能把本轮已定位的 SCR 等待复位当成它的根因。
- 早期某张 JPG 偶发“没有缩略图”，原记录 66 次点击和 50 MB 连读未复现。保留各层错误计数；本轮插拔修复不等于已证明解决这个历史现象。
- 文件页长目录、文本真实文件、不同卡、坏图片、快速换卡等边界可按修改范围补测。本轮文本使用桌面假文件；相机卡未写入测试文件。
- 卡槽无检测脚，CMD13 轮询不能可靠识别两次检查间迅速换卡的身份变化；若需要支持，单独设计身份/挂载代际检查。

## 当前资源与开发约束

资源取自 `66ad20c` 对应文件页收尾构建及 `handbook/f407/gui/files-browser-test.txt`，不是本轮重新测量。

| 资源 | 用量/余量 | 解释 |
|---|---:|---|
| Flash | 462732 / 1048576 B | 约 44.1% |
| 片内 RAM 区域 | 118176 / 131072 B | 链接器占用，约 90.2%；不要与运行时剩余堆混为一谈 |
| CCM | 60416 / 65536 B | 约 92.2%，DMA 不能访问 |
| 外部 SRAM 静态区 | 950532 / 1048576 B | 约 90.7%，并非仍有近 1 MB 空闲 |
| LVGL 内存池峰值 | 35664 / 45056 B | 本轮文件页路径；不是所有操作的最坏上界 |
| StationTask 最少剩余栈 | 2668 / 8192 B | 本轮连续读图及诊断路径 |
| FreeRTOS 最小剩余堆 | 18816 B | 总堆配置 32768 B |

外部 SRAM 尾部 `0x680F0000` 起的 64 KB 还被 `sram` / `sdbench` / `sdsum` 等工具当作暂存区。扣除它后，静态数据末尾到该暂存区之间约 **32508 B**，不能把链接器显示的剩余约 98 KB 全部用于新缓冲。新增存储、自检和 DMA 功能必须先核对内存区间。

## 建议接续顺序与完成标准

建议顺序：本轮文档整理 → **A01 设备页任务明细** → **A03 响应/阻塞测量** → 按上位机学习目标在 **A04 对时**、**A05 波形闭环**之间选择。A02 可穿插，但先确认写入区域。A07 等写卡条件明确后再做；B、C、D 各项依赖实际硬件和目标选取。

每项按：确认学习目标和边界 → 核对旧驱动/已有实验 → 必要时修改 `.ioc` 并运行 `tools/cubemx_generate.sh` → 本机 `-j2` 构建 → 烧录正式固件实测 → 记录结果、内存和失败路径 → 同步手册与清单 → 本地提交。

界面构建使用当前 `App/lv_ui.c` 的按需创建/离开销毁机制，不再沿用旧计划的“开机建好所有页面”。中文文字变化时检查 `tools/make_cjk_font.sh` 的页面范围。需要看屏、接线、跳线、外部设备的操作一次说明清楚；当前硬件未确认的项目先做可独立完成的准备。
