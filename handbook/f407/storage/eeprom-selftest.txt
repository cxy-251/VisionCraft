A02 EEPROM 末页自检，2026-10-15
基线 f543a5f。本机 Release 编译、OpenOCD 烧录并 Verify OK，正式固件保留。
FLASH 478052 / 1048576 B；RAM 124456 / 131072 B；CCM 60416 / 65536 B；EXTSRAM 950532 / 1048576 B。
较 A05：Flash +1360 B，片内 RAM +56 B；无新增任务/队列/动态分配。EEPROM 原互斥锁改用优先级继承。
执行条件：目前无额外 USB 口，A06 串口实连暂缓；此项无需接线。未访问 SD，未进入 FILES。
只测试 EEPROM 最后一页 248..255，原始8字节先保存；全部256字节比较在主机内存完成，不归档业务参数内容。
普通写禁止进入该保留页；读写拒绝越界/空指针/空长度。互斥锁等待20 ms，单次 HAL 读写10 ms；ACK单次1试/2 ms，按10 ms预算检查截止并 osDelay(1)。
这些是各等待预算，不是完整函数/任务/故障的硬实时上界；多页写仍由原接口同步拆页。
自检每轮最多一个 EEPROM 操作；写失败也可能已改变芯片，因此仍尝试恢复。

错误码：0=无，1=备份读，2=测试写，3=测试读，4=码值不符，5=恢复I/O，6=恢复值不符。
备份只存在RAM；中途断电不能承诺恢复保留页，配方/设置不占此页。

==== 4. 复现
source scripts/steamdeck-env.sh
nice -n 19 cmake --build build --target tst_eeprom_diag tst_eeprom_driver -j2
XDG_CONFIG_HOME=/tmp/vc-ee-config ctest --test-dir build --output-on-failure -R '^tst_eeprom_(diag|driver)$'
本机编译/烧录正式固件后：PYTHONDONTWRITEBYTECODE=1 python3 tools/eeprom_diag_probe.py --output /tmp/vc-ee-board
手工：远程终端或板上终端输入 eetest start，稍后 eetest 查结果；取消用 eetest cancel，恢复失败用 eetest retry。
此功能由显式命令触发，不做周期写入；SPI Flash 及统一存储诊断界面仍是 A02 待办。
