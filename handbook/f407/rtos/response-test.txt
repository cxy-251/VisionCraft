==== 0. 条件与范围
固件：38a4dea 后的 A03 计时改动，Release，168 MHz，未更改任务划分。
FLASH 469460 / 1048576 B；RAM 119024 / 131072 B；CCM 60416 / 65536 B；EXTSRAM 950532 / 1048576 B。
较 A01：Flash +1036 B，RAM +336 B；无新增 RTOS 任务/队列/堆分配。
HOME/DEVICE/STATION，终端白名单 uptime/sensors/ps/free；不进入 FILES，不执行任何卡操作。
四阶段同一启动：每阶段先清统计，再运行负载；50 ms 遥测一直并发。
每阶段结束额外执行 ps/free 采样资源，计时统计包含这两条诊断。
idle：30 个 4 B PING 和输入标记；shell：24 条循环诊断，并发 256 B PING。
image：5 张 160x120 RGB565（每张 38400 B），每批至多四块 1000 B，并发 uptime、256 B PING。
controlled：5 次 180 ms 可抢占 CPU 工作；每次一个输入标记、三条 uptime、八个短 PING。
探针 RTT 客户端启用 TCP_NODELAY；OpenOCD RTT polling_interval=1 ms。

==== 4. 复现与限制
source scripts/steamdeck-env.sh
cd firmware/station && nice -n 19 cmake --build --preset Release -j2
回到根目录，按 CLAUDE.md 烧录并校验当前 Release 固件。
python3 tools/response_probe.py --output /tmp/vc-response-a03
输出 run.txt 可由 shell 重定向保存；results.json 和 OpenOCD 日志写到指定目录。
协议编码和 CRC 使用临时编译的 protocol/vc_protocol.c；进程结束删除临时共享库。
每个窗口内不暂停 CPU，窗口结束短暂停核取得一致快照，再恢复运行。
input_mark 是 LinkTask 到输入轮询的标记，不是实际触摸到显示的延迟。
image_work 不是屏幕最终呈现延迟；本轮只验证协议确认和缓冲消费，未做显示像素回读。
DWT 包含抢占/等待，32 位约 25.6 秒回绕；本轮相邻采样和有界工作均远短于此。
over20ms 是严格 >20 ms 的次数，不能当作丢帧率，正常刷新略超 20 ms 也计入。
PING 包含 TCP/OpenOCD/排队/Python 调度；各阶段负载长度不同，不能当成相同条件对比。
传图时 PING 排在四个图片分块之后，其 RTT 不等于板内锁等待。
鼠标/蜂鸣队列、结果覆盖等为零只表示本轮未发生；未施加这些路径的满队列压力。
未覆盖 RTT 满缓冲/停止读取、所有终端命令、真实触摸链路和存储，不能外推最坏上界。
决策：当前诊断与 RTT 图像负载暂不拆任务；未来慢功能先分步或通过有界工作交接，LVGL 仍由 StationTask 操作。
脚本结束关闭 50 ms 遥测并留在 DEVICE；后续 Qt 探针使用其默认 1000 ms 订阅。
Qt 探针退出后恢复 s_periodMs=0；最终读取确认遥测关闭、work_ms/work_active/input_request 均为 0，页面为 DEVICE。
