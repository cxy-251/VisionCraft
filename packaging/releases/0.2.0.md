VisionCraft 0.2.0 以 Qt / QML 与 OpenCV 教学为主线，整合新版视觉实验、学习手册和 STM32 工位通信。

## 本次更新

- QML 视觉实验覆盖图像工坊、模板匹配、批量质检、屏幕流、节点管线与开发工具；旧版 Widgets 实验室入口保留。
- 工位支持检测记录、固定样本及参数对比；波形支持电脑端保存和离线回放，节点管线可保存工程。
- 应用内 Qt 56 章、OpenCV 54 章，新增音视频、Qt Quick GPU / ShaderEffect 等课程及独立示例，继续提供衔接、F407 与系统卷。
- 屏幕输入统一使用 Qt Multimedia，修复 Wayland 黑屏与屏幕共享会话未释放问题，并修复相关 QML 布局循环。
- STM32F407 当前范围收尾：日常使用板载 USB_232 通信，保留 ST-Link RTT；固件同时提供 ELF / BIN。
- 跨平台发布统一使用 Qt 6.9.1。Windows 新增 MSI、EXE 安装程序与单文件便携版，不再以 ZIP 作为 Windows 发布包。

## 下载选择

- **Windows x64**：选择 `.msi` 或 `-setup.exe` 安装，二者安装的是同一程序；免安装选择 `-portable.exe`。便携版设置保存在程序旁的 `VisionCraft-data` 文件夹，请放在可写目录。
- **Linux x86_64**：下载 `.AppImage`，赋予执行权限后运行。Wayland 屏幕共享需要桌面提供 ScreenCast portal / PipeWire。
- **macOS Apple Silicon**：下载 `.dmg`。
- **STM32F407**：`station.bin` / `station.elf` 为配套固件，桌面学习无需连接开发板。

各平台由 GitHub Actions 构建并运行仓库已有检查；这不代表已在所有系统上完成交互或硬件实测。
