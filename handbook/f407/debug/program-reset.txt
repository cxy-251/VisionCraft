# 本板 BOOT0 接高电平。每种复位方式之后，停下 CPU 看 PC 在哪（本板实测）
$ openocd … -c "reset run" -c "sleep 300" -c halt …
PC = 0x1fff3846                  ← 系统存储区：芯片自带的 bootloader
$ openocd … -c "reset halt" -c halt …
PC = 0x1fff3da0                  ← 同上
$ openocd -f interface/stlink.cfg -f target/stm32f4x.cfg -c "program firmware/station/build/Release/station.elf verify reset exit"
** Verified OK **
** Resetting Target **
$ openocd … -c halt …
PC = 0x1fff3694                  ← 烧录成功、校验通过，复位后照样进了 bootloader
