==== 1. std::vector：拷贝就是复制全部数据 ====
  b = a 之后：不同的内存

==== 2. std::move：把数据「交出去」，不复制 ====
  b 用的是 a 原来的内存吗？是
  a.size() = 0（被移走后是有效但未指定的状态，标准库容器实际是空的）
  std::move 一个 const 对象：不同的内存

==== 3. QByteArray：拷贝时共享，写入时才复制 ====
  b = a 之后：同一块内存
  b[0] = 'x' 之后：不同的内存，a[0] 仍是 'a'

==== 4. 代价：拷贝 1000 次 8 MB ====
  std::vector 拷贝：               863.2 ms
  QByteArray 拷贝 + at(0)：        0.015 ms
  QByteArray 拷贝 + copy[0]：      876.5 ms

==== 5. 坑：遍历共享的 Qt 容器也可能触发复制 ====
  非 const 遍历之后：不同的内存
  std::as_const 遍历之后：同一块内存
