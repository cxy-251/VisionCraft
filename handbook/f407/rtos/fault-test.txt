==== 1. 第一版：tools/fault_probe.tcl（注入故障、等复位、读复位原因和记录）====
$ openocd ... -c "set g_fault_inject 0x…; set g_reset_flags 0x…; set g_last_fault 0x…; set uwTick 0x…" -f tools/fault_probe.tcl -c exit
开机：RCC_CSR=0x1e000000（软件复位、上电、复位脚、欠压）；没有故障记录
看门狗：IWDG_PR=4 IWDG_RLR=2000；调试时冻结看门狗 DBGMCU_APB1_FZ=0x00001800
不做任何事等 10 秒：毫秒计数从 4141 走到 14137（没有被看门狗复位）
1. 空指针调用：写入后约 0.1 秒复位
  RCC_CSR=0x14000000（软件复位、复位脚）
  HardFault：PC=0x00000000 LR=0x08007e09 xPSR=0x60000000 CFSR=0x00020000 HFSR=0x40000000 SP=0x20003838 任务=stationTask
2. 递归把 StationTask 的栈用爆：写入后约 0.1 秒复位
  RCC_CSR=0x14000000（软件复位、复位脚）
  栈溢出：任务=stationTask SP=0x200018b8
3. StationTask 卡死（自己就是喂狗的）：写入后约 4.0 秒复位
  RCC_CSR=0x24000000（看门狗、复位脚）
  没有故障记录
4. EnvTask 卡死（StationTask 照常运行）：写入后约 6.0 秒复位
  RCC_CSR=0x24000000（看门狗、复位脚）
  任务没有报到，停止喂狗：任务=linkTask
